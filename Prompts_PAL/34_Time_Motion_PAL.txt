ĐỀ BÀI MẪU 1: Một chất điểm dao động điều hòa với biên độ 4 cm. Biết trong một chu kì, khoảng thời gian để chất điểm có vận tốc không vượt quá 4.pi.sqrt(3) cm/s là 2T/3. Tìm chu kì dao động.

LỜI GIẢI:
[1. GIẢI THÍCH LÝ THUYẾT]:
- Điều kiện độ lớn vận tốc không vượt quá vx (|v| <= vx) ứng với vùng vật ở gần hai biên (chiếm thời gian 2T/3).
- Khoảng thời gian vật có độ lớn vận tốc lớn hơn vx (|v| > vx) trong một chu kỳ là delta_t' = T - 2T/3 = T/3 (vùng gần VTCB).
- Thời gian vật đi từ VTCB (vmax) đến vị trí có tốc độ vx là t1 = delta_t' / 4 = T/12.
- Với t1 = T/12 tính từ VTCB, li độ tương ứng của vật là |x| = A / 2, từ đó suy ra mối liên hệ vx = omega * A * sqrt(3) / 2.
- Chu kỳ dao động được tính theo công thức T = 2.pi / omega.

def solution():
    import sympy as sp
    
    # Khai báo tham số đầu vào
    A = 4.0                               # cm
    vx = 4 * sp.pi * sp.sqrt(3)           # cm/s
    
    # Bước 1: Từ |x| = A/2, rút ra hệ thức vx = omega * A * sqrt(3) / 2
    # vx = omega * (A * sqrt(3) / 2) => omega = vx / (A * sqrt(3) / 2)
    omega = vx / (A * sp.sqrt(3) / 2)
    
    # Bước 2: Tính chu kỳ T = 2*pi / omega
    T = 2 * sp.pi / omega
    
    result = float(T)
    return result

def solution():
    import sympy as sp
    
    # Khai báo tham số đầu vào
    A = 5.0                # cm
    vx = 5 * sp.pi         # cm/s
    
    # Bước 1: Từ |x| = A*sqrt(3)/2, suy ra vx = omega * A / 2
    omega = vx / (A / 2.0)
    
    # Bước 2: Tính chu kỳ T = 2*pi / omega
    T = 2 * sp.pi / omega
    
    result = float(T)
    return result

    omega = vx / (A / sp.sqrt(2))
