- Vị trí đích: Gia tốc a = a_max / 2 tương ứng với li độ x = -A / 2.
- Trạng thái đầu (t = 0): Vận tốc v = v_max / 2 > 0 và thế năng đang tăng (vật đi ra xa VTCB) nên li độ ban đầu là x0 = +A.sqrt(3) / 2 và vật đang đi về phía biên dương (+A).
- Hành trình ngắn nhất: Từ +A.sqrt(3) / 2 ra biên dương (+A) mất thời gian T/12, từ biên dương về VTCB (0) mất T/4, và từ VTCB đến vị trí đích x = -A / 2 mất T/12.

def solution():
    import sympy as sp
    
    # Khai báo tham số đầu vào (chuẩn hóa cm, s)
    v_max = 80.0                # cm/s
    a_max = 400.0 * sp.pi       # 4.pi m/s^2 = 400.pi cm/s^2
    
    # Bước 1: Tính tần số góc omega và chu kỳ T
    omega = a_max / v_max
    T = float(2 * sp.pi / omega)
    
    # Bước 2: Phân tích các khoảng thời gian lẻ theo trục phân bố thời gian
    t1 = T / 12.0               # Từ +A*sqrt(3)/2 ra +A
    t2 = T / 4.0                # Từ +A về VTCB (0)
    t3 = T / 12.0               # Từ VTCB (0) đến -A/2
    
    # Bước 3: Tính tổng thời gian di chuyển
    t = t1 + t2 + t3
    
    result = round(float(t), 3)
    return result
