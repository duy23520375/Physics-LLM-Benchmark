[1. GIẢI THÍCH LÝ THUYẾT]:
Trong dao động điều hòa, gia tốc ($a$) và li độ ($x$) liên hệ với nhau qua phương trình đặc trưng $a = -\omega^2 x$, trong đó $\omega$ là tần số góc cần tìm và $\omega$ luôn dương.

[2. TÍNH TOÁN CÔNG THỨC VÀ THAY SỐ]:
def solution():
    import sympy as sp
    
    # Phương trình đề bài: 160*x + a = 0 => a = -160*x
    # So sánh với dạng chuẩn a = -omega^2 * x => omega^2 = 160
    omega_squared = 160
    
    # Bước 1: Tính tần số góc omega = sqrt(160) = 4*sqrt(10)
    # Vì pi^2 = 10 nên sqrt(10) = pi => omega = 4*pi
    omega_val = sp.sqrt(omega_squared)
    
    # Biểu diễn theo pi (sqrt(160) = 4*pi)
    omega_exact = 4 * sp.pi
    
    result = str(omega_exact)
    return result
