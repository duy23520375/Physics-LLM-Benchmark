ĐỀ BÀI MẪU 1: Một con lắc lò xo dao động điều hòa với biên độ 10 cm. Trong một chu kỳ, khoảng thời gian để vật có độ lớn gia tốc không vượt quá 50 cm/s^2 là T/3. Lấy pi^2 = 10. Tìm tần số dao động.

LỜI GIẢI:
[1. GIẢI THÍCH LÝ THUYẾT]:
- Miền li độ: Điều kiện độ lớn gia tốc không vượt quá ax (|a| <= ax) tương ứng với vùng vật ở gần VTCB (li độ |x| <= xa).
- Thời gian t1: Khoảng thời gian để |a| <= ax trong một chu kỳ là Delta_t = T / 3, suy ra thời gian vật đi từ VTCB đến li độ xa là t1 = Delta_t / 4 = T / 12.
- Dựa vào trục phân bố thời gian, thời gian t1 = T / 12 tính từ VTCB tương ứng với li độ xa = A / 2.
- Tần số góc và tần số dao động được tính từ gia tốc tại li độ xa: omega = sqrt(ax / xa) và f = omega / (2 * pi).

def solution():
    import sympy as sp
    
    # Khai báo tham số đầu vào
    A = 10.0      # cm
    a_x = 50.0    # cm/s^2
    
    # Bước 1: Tính li độ tại biên độ gia tốc xa = A / 2
    x_a = A / 2.0
    
    # Bước 2: Tính omega^2 = a_x / x_a và tần số góc omega
    omega_sq = a_x / x_a
    omega = sp.sqrt(omega_sq)
    
    # Bước 3: Tính tần số dao động f = omega / (2*pi) với pi = sqrt(10)
    pi_val = sp.sqrt(10)
    f = omega / (2.0 * pi_val)
    
    result = float(f)
    return result

def solution():
    import sympy as sp
    
    # Khai báo tham số đầu vào
    A = 20.0       # cm
    a_x = 100.0    # cm/s^2
    
    # Bước 1: Tính li độ tại biên độ gia tốc xa = A / 2
    x_a = A / 2.0
    
    # Bước 2: Tính omega^2 = a_x / x_a và tần số góc omega
    omega_sq = a_x / x_a
    omega = sp.sqrt(omega_sq)
    
    # Bước 3: Tính tần số dao động f = omega / (2*pi) với pi = sqrt(10)
    pi_val = sp.sqrt(10)
    f = omega / (2.0 * pi_val)
    
    result = float(f)
    return result
