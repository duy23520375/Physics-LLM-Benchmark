ĐỀ BÀI MẪU: Một vật dao động điều hòa với phương trình: x = 12cos(2*pi*t - pi/6) (cm) (t tính bằng s).
a) Xác định biên độ, chu kì, tần số và pha ban đầu.
b) Xác định chiều dài quỹ đạo.
c) Khi t = 0,25 s thì li độ của vật bằng bao nhiêu?
---
LỜI GIẢI:
[1. GIẢI THÍCH LÝ THUYẾT]:
Xác định các thông số bằng cách so sánh phương trình đề bài với dạng chuẩn x = Acos(omega*t + phi) và sử dụng công thức chiều dài quỹ đạo L = 2A.

[2. TÍNH TOÁN CÔNG THỨC VÀ THAY SỐ]:
def solution():
    import sympy as sp
    
    # Khai báo tham số từ phương trình chuẩn
    A = 12.0                  # cm
    omega = 2 * sp.pi         # rad/s
    phi = -sp.pi / 6          # rad
    t_c = 0.25                # s
    
    # Câu a: Tính chu kỳ T và tần số f
    T = float(2 * sp.pi / omega)
    f = float(1 / T)
    
    # Câu b: Chiều dài quỹ đạo
    L = 2 * A
    
    # Câu c: Li độ tại t = 0,25 s
    x_c = float(A * sp.cos(omega * t_c + phi))
    
    return {
        "a": {"A": A, "T": T, "f": f, "phi": str(phi)},
        "b": {"L": L},
        "c": {"x": round(x_c, 4)}
    }
