ĐỀ BÀI MẪU 1 (ĐÃ Ở DẠNG CHUẨN): Một vật tham gia đồng thời hai dao động cùng phương: x1 = 4cos(5t + pi/2) cm và x2 = 3cos(5t) cm. Tốc độ cực đại của vật là?
---
LỜI GIẢI:
[1. GIẢI THÍCH LÝ THUYẾT]:
Các phương trình dao động thành phần đều đã ở dạng chuẩn cos. Sử dụng công thức tính biên độ tổng hợp A để tìm tốc độ cực đại v_max = omega.A.

def solution():
    import sympy as sp
    
    # Khai báo tham số đầu vào
    A1 = 4.0          # cm
    phi1 = sp.pi / 2  # rad
    A2 = 3.0          # cm
    phi2 = 0.0        # rad
    omega = 5.0       # rad/s
    
    # Bước 1: Tính độ lệch pha
    delta_phi = phi2 - phi1
    
    # Bước 2: Tính biên độ tổng hợp A
    A = sp.sqrt(A1**2 + A2**2 + 2 * A1 * A2 * sp.cos(delta_phi))
    
    # Bước 3: Tính tốc độ cực đại v_max = omega * A
    v_max = omega * A
    
    result = float(v_max)
    return result

def solution():
    import sympy as sp
    
    # Chuẩn hóa x1 từ dạng sin sang cos: phi1 = -pi/6 - pi/2 = -2*pi/3
    A1 = 8.0               # cm
    phi1 = -2 * sp.pi / 3  # rad
    A2 = 8.0               # cm
    phi2 = -2 * sp.pi / 3  # rad
    omega = 2.0            # rad/s
    
    # Bước 1: Tính độ lệch pha
    delta_phi = phi2 - phi1
    
    # Bước 2: Tính biên độ tổng hợp A
    A = sp.sqrt(A1**2 + A2**2 + 2 * A1 * A2 * sp.cos(delta_phi))
    
    # Bước 3: Tính tốc độ cực đại v_max = omega * A
    v_max = omega * A
    
    result = float(v_max)
    return result
